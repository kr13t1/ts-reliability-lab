## Основания чисел и рисунков

Единица наблюдения — запись 1601/A, ось X; единица парного сравнения — фиксированный интервал. 32 сценария дают 96 результатов методов. В таблицах приведены средние оконных метрик по восьми стартам с округлением до четырёх знаков. Значение Linear 1,0000 при L=200 получается из 1,0000067905; после округления нельзя определять знаки парных разностей. Графики и таблицы получены на зафиксированных данных. ## Решения перед подачей

Для обсуждения указаны Кристина Прозорова и университет. Автору и преподавателю предстоит подтвердить точное написание имени, порядок авторства, кафедру, e-mail, классификационные коды и соответствие объёма текущему выпуску. Публичный регламент именно этого набора, включая правила AI-содействия, в просмотренных источниках не установлен. Авторская вычитка, независимая редакционная проверка 05 и решение 00 о подаче остаются отдельными шагами. [Материалы для беседы](ADVISOR_BRIEF.md)
