# Черновик научной статьи по шаблону МИСИС

Тема: сравнение поточечной ошибки и ошибки первых разностей при восстановлении измерений.
Это исследовательский описательный результат одного субъекта, не новый алгоритм и не утверждённая тема ВКР.

Оформление: точная копия misisarticle.cls из sadekovlar/misis-article-latex (LPPL 1.3c), XeLaTeX, A4, две колонки. Сборка из этой папки: xelatex article.tex (два раза) либо tectonic article.tex. Поля ФИО, кафедры, адреса электронной почты и классификационные коды требуют реального заполнения. Подготовленный текст должен пройти самостоятельную авторскую правку и проверку допустимости AI-содействия конкретным изданием.

Четыре оригинальные PNG из экспериментального артефакта, совпадающие с файлами draft PR #43, представлены как Git blobs без перерисовки. Экспериментальный HEAD 7099e4f0205062e37f4ce0ef7c562eac436fcd6b. Независимый аудит: https://github.com/kr13t1/ts-reliability-lab/pull/41#issuecomment-7014303678. Точные CSV — в PR #43. Исходные сырые записи не включены.
