**Объект:** `demo/index.html`, автономный интерактивный прототип (не G2.4 upstream viewer и не научный эксперимент). Фактические входы сверены при локальной сборке 2026-11-15, но независимого 05-аудита публикационной версии ещё нет.

- WISDM Smartphone and Smartwatch Activity and Biometrics Dataset; Gary M. Weiss (2019); UCI repository 507; DOI https://doi.org/10.24432/C5HK59; CC BY 4.0.
- Внешняя исходная запись `data_1600_accel_phone.txt`: SHA256 `40b7f60880b495ccb3c345b9ab11216dfa6bbb2bb887bcb45fb55020278fc22f`, в этот PR **не включена**.
- Исходный Walking reference CSV: SHA256 `8bf61ee71f68e0648ead7bc8eb8b6c44414e28411bd6de65e5f9dadf9c28eb38`, использует заранее принятые сведения G2.2/G2.3.
- Фиксированный учебный эксперимент: subject 1600; Walking / A N=3574, Standing / E N=3572; искусственный X freeze `[1191,2382)` удерживает значение `x[1190]`; Y и Z не изменены.
- Детектор: существующий G2.4 exact-equality constant-run baseline, L=3, epsilon=0; истинная маска определяется **нашим вмешательством**. TP/FP/FN/TN для Walking freeze 1191/1/0/2382; ошибочная опорная точка i=1190.
- SHA256 `demo/index.html` по локальному публикационному комплекту: `9d45b2f740415f19d8857beafa0cffd6150748571eb94841744cb085c200a684`; повторить проверку после извлечения Git blob, не заменять silent hash update.

**Смысл ограничений:** Контроль `Z=0` говорит только об отсутствии **нашего** повреждения, не о физически исправном датчике. Нет downstream классификации, аппаратных меток неисправностей, независимых испытуемых и доказанного нового метода. 1191 TP — связанные отсчёты одного эпизода.

Проверки этого черновика и GitHub CI не равны независимому 05 решению GO для Хабра. Статья и демо остаются `draft`, пока не заменены URL/иллюстрации и не завершён публикационный аудит.

## Восстановленная сборка публикационной версии (2026-11-16)

Оригинальные `build_demo.py`, `template.html`, `test_demo.py` из прежнего локального публикационного архива **не обнаружены** в доступных ветках GitHub. Вместо выдачи замены за оригинал из уже размещённого `demo/index.html` **без изменения байтов HTML** отдельно извлечены `source/template.html` и `source/payload.json`. Новый `build_demo.py` выполняет точное восстановление HTML (SHA-256 `9d45b2f740415f19d8857beafa0cffd6150748571eb94841744cb085c200a684`) с независимой от UI арифметической проверкой известного freeze. Это `snapshot-to-HTML`, **не** `raw-WISDM-to-HTML`.

Векторные `figures/overview.svg` и `figures/boundary.svg` построены по этому сохранённому массиву, с подписанными индексами. Они — дополнительные редакционные иллюстрации, не фотография экрана, не внешний датасет и не измерение новых эффектов. Их наличие **не** подменяет ручной browser-review интерактивного HTML.

**Граница воспроизводимости:** по замороженному массиву и сохранённому контракту G2.4 проверяются назначенная маска, предсказание exact runs и confusion counts на данном одном событии. Сама аутентичность чисел в HTML относительно официально загруженного raw-набора отдельно не воспроизводилась в восстановленном builder. Публичная публикация требует нового scoped аудита 05 по конкретному Git SHA и разрешения владельца на публичный URL.
