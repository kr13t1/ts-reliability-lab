# Хабр — единый рабочий комплект в GitHub (draft)

**Состояние:** черновик, **не опубликован и не аудирован 05**. Никаких пересылок архива между чатами: для просмотра исходников и аудита достаточно [этого PR](https://github.com/kr13t1/ts-reliability-lab/pull/30) и его фиксированного HEAD SHA.

- **ARTICLE.md** — готовый инженерный текст с явно помеченными ещё не вставленными внешними ссылками и иллюстрациями.
- **demo/index.html** — полностью автономный интерактивный прототип (визуализация трёх заранее заданных случаев по WISDM); он **не обучает**, не пересчитывает G2.4 и не обрабатывает пользовательские сигналы.
- **test_publication.py** — проверка байтового отпечатка HTML, встроенности данных, наличия контролов, границ и отсутствия сетевых API. Это не независимая научная валидация и не запуск исходного генератора.
- **PROVENANCE.md** — исходное происхождение и пределы допустимых утверждений.

Факты: WISDM subject 1600, Walking/A 3574 отсчёта и Standing/E 3572; искусственное удержание X в [1191,2382) по x[1190]; назначено 1191; baseline G2.4 отметил [1190,2382), TP1191, FP1. WISDM CC BY 4.0, DOI 10.24432/C5HK59.
