## Повторить из корня репозитория

```bash
python publications/habr/build_demo.py --check
python -m unittest discover -s publications/habr -p 'test_*.py' -v
```

Для создания идентичного HTML в отдельной директории:

```bash
python publications/habr/build_demo.py --output /tmp/habr-demo/index.html
```

Запуск `--check` не переписывает checked-in HTML. Во втором вызове создаётся папка выхода. Используется стандартная библиотека Python (без raw-файлов и без сети).

Для просмотра откройте `publications/habr/demo/index.html` локальным браузером. Все ряды встроены в HTML.
