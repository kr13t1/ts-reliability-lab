# Repair pilot — exploratory, not G3
Fixed before calculation: one previously inspected walking recording, subject 1600, X only. 8 predetermined starts, 4 lengths, one freeze per scenario with x[s:e]=x[s-1]. Each run starts from the same original recording. No held-out test, no claims of generalization. Intervals across lengths overlap and all belong to one subject. Oracle mask [s,e) provided to every repair method; no detector evaluation. No additional raw subjects used. Baselines: unchanged corrupted signal / last observation carried forward (identical under freeze), offline linear interpolation using observed endpoints, recursive AR(10) least squares with intercept fitted on 256 preceding observed samples only; no clipping or tuning. Linear has future boundary access, AR does not; not a fair causal leaderboard. Compare MAE/RMSE inside mask, check outside unchanged; summarize mean per-window RMSE by length and count wins against hold. All scenarios included, no inferential statistics. Illustrate fixed start 1200, lengths 20 and 200 regardless of outcome. G2/G3 status unchanged; independent audit required before claims. No new algorithm.
