## 1. Граница задачи

G1 — **демонстрация**, не исследование качества классификаторов: две синтетические 10-секундные записи трёхосного динамического ускорения, известные метки «покой»/«ходьба», одно замирание оси `x`, один фиксированный RMS-классификатор. Показать `X_ref`, `X_obs`, истинную маску `Z`, численную ошибку повреждения и ответ классификатора **до/после**. Данные, параметры и порог не подбираются по результатам.

## 2. Сигналы и генератор

- Две записи с идентификаторами `rest`, `walk`; метки `y_rest=0` (покой) и `y_walk=1` (ходьба).
- Частота `fs=20 Hz`; длительность `D=10 s`; число отсчётов `T=200`; время `t_i=i/fs`, `i=0,…,199` (последнее `9.95 s`).
- Оси `c=0,1,2` соответствуют `x,y,z`. Каждый `X_ref^(j) ∈ R^(3×200)`; единица значений — `m/s²`, **условное динамическое ускорение с удалённой гравитацией**, а не физически проверенный сигнал смартфона.
- `dtype=float64`; **seed `20261101`**. Единственный генератор `rng = numpy.random.Generator(numpy.random.PCG64(20261101))`; **одним вызовом** `eps = rng.standard_normal(size=(2,3,200), dtype=numpy.float64)`. Порядок записей в первом измерении: `rest`, затем `walk`. Для контрольных чисел зафиксирован `numpy==2.3.5`.
- Шум `σ=0.03 m/s²`; частота искусственных колебаний `f=2 Hz`; амплитуды `A=(0.8,0.5,0.3) m/s²`; фазы `φ=(0,π/3,π/2)` радиан.

Для каждого `c,i`:

\[
X_{\mathrm{ref},c,i}^{(rest)}=\sigma\,\varepsilon_{0,c,i},\qquad
X_{\mathrm{ref},c,i}^{(walk)}=A_c\sin(2\pi f t_i+\varphi_c)+\sigma\,\varepsilon_{1,c,i}.
\]

**Никаких** дополнительных фильтров, нормализации, случайных фаз, смещения силы тяжести, обучения или разделения на train/test. Шум нужен только для неидеально гладкого примера; он не моделирует реальное распределение ошибок акселерометра.

## 3. Единственный оператор: замирание оси

Одинаково применяется **отдельно к каждой** из двух записей; остальные оси неизменны. Параметры:

| Поле | Значение |
|---|---|
| `axis` | `0` (`x`) |
| `start_s`, `end_s` | `3.0`, `6.0` секунды |
| `start_idx`, `end_idx` | `s=60`, `e=120`, полуинтервал `[60,120)` |
| `anchor_idx` | `s−1=59` (`2.95 s`) |
| `strength` | `α∈[0,1]`, основной показ `α=1.0`; контроли `α=0.0` и `α=0.5` |
| `corruption_seed` | `null`: оператор неслучайный |

При `i∈[s,e)` на оси `c=0`:

\[
X_{\mathrm{obs},0,i}=(1-\alpha)X_{\mathrm{ref},0,i}
+\alpha X_{\mathrm{ref},0,s-1}.
\]

Во всех других точках `X_obs=X_ref`. Использовать **исходное** значение `X_ref[0,59]`, а не изменяемый массив. При `α=1` это точное удержание последнего отсчёта перед событием; при `α=0` — тождественный оператор. Правая граница `i=120` **не повреждается**.

`Z ∈ {0,1}^(3×200)` — **маска назначенных точек инъекции**, а не выход детектора и не проверка `X_obs != X_ref`:

\[
Z_{c,i}=\mathbf1\{\alpha>0\}\mathbf1\{c=0\}\mathbf1\{60\le i<120\}.
\]

Следовательно, при `α>0` ровно 60 единиц на запись; при `α=0` **вся маска нулевая**. При случайном численном совпадении изменённого и исходного значений внутри интервала `Z` всё равно равно 1: оно обозначает область применённого оператора. Класс `y` не изменяется.

## 4. Один baseline и измеряемые величины

**Baseline `f`: фиксированная RMS-эвристика классификации активности** (не детектор неисправности). Для любой записи `X ∈ R^(3×200)`:

\[
\bar X_c=\frac1T\sum_{i=0}^{T-1}X_{c,i},\quad
S(X)=\sqrt{\frac1{3T}\sum_{c=0}^{2}\sum_{i=0}^{T-1}(X_{c,i}-\bar X_c)^2},\quad
\hat y(X)=\mathbf1\{S(X)\ge 0.20\;\mathrm{m/s^2}\}.
\]

`S` измеряется в `m/s²`; порог `0.20 m/s²` задан **до запуска** как условное число между заданными масштабами покоя и ходьбы. Оно не оценивается по двум записям и не оптимизируется. Применить **одну и ту же** функцию к `X_ref` и `X_obs`.

**Первичная ошибка повреждения** для каждой записи и любого `α`, включая нулевое (всегда определена):

\[
E_{\mathrm{event}}(\alpha)=\sqrt{\frac1{60}\sum_{i=60}^{119}
(X_{\mathrm{obs},0,i}-X_{\mathrm{ref},0,i})^2}\quad[\mathrm{m/s^2}].
\]

Она измеряется **на заранее назначенном интервале**, а не делением на `sum(Z)`, которое равно нулю при `α=0`. При `α>0` она совпадает с RMSE на единицах маски. Для данного оператора верно `E_event(α)=α E_event(1)` при `α∈[0,1]` с точностью вычислений. Это **ошибка наблюдения относительно известного синтетического эталона**, не ошибка восстановления: восстановления в G1 нет.

**Ошибка baseline** по каждой записи, без статистических претензий:

\[
e_{\mathrm{ref}}=\mathbf1\{\hat y(X_{\mathrm{ref}})\ne y\},\qquad
e_{\mathrm{obs}}=\mathbf1\{\hat y(X_{\mathrm{obs}})\ne y\},
\]

где `e∈{0,1}` — ошибка/верный ответ, без единиц. Также показывать `S_ref`, `S_obs`, `ΔS=S_obs−S_ref` (в `m/s²`) и оба предсказания. **Изменение RMS необязательно монотонно по `α`; изменение класса и рост ошибки классификации не обязательны.** Никаких «accuracy на датасете», доверительных интервалов и balanced accuracy по двум демонстрационным записям.

## 5. Контрольные случаи и тесты

| Тест | Строгий ожидаемый результат |
|---|---|
| Повторный запуск | При том же `seed`, конфигурации и зафиксированной версии NumPy массивы `X_ref`, `X_obs`, `Z` и численные поля результатов воспроизводятся (`array_equal` для массивов при одинаковом окружении). |
| Форма/метки | На каждую запись `(3,200)` и `float64`; `y=0/1`; все значения конечны; нет `NaN/Inf`. |
| Основной дефект, `α=1` | `X_obs[0,60:120] == X_ref[0,59]`; вне этого интервала и на `y,z` значения точно равны `X_ref`; `sum(Z)=60`, только ось `x`. В `i=59` и `i=120` вмешательства нет. |
| Половинная сила, `α=0.5` | `X_obs[0,60:120]` соответствует указанной линейной формуле; `Z` содержит 60 единиц; `E_event(0.5)≈0.5·E_event(1)` с абсолютной погрешностью не более `1e−12 m/s²`. |
| Нулевая сила, `α=0` | `array_equal(X_obs,X_ref)`; `sum(Z)=0`; `E_event=0`; `ΔS=0`; предсказания совпадают. |
| Ручная проверка метрик | На простом фиксированном искусственном массиве отдельно пересчитать средние осей, `S`, `E_event` и `e` по формулам; допуск `1e−12` для вещественных метрик. |
| Отсутствие скрытой подгонки | У baseline один неизменный порог `0.20`; никакой подбор по `X_obs`, меткам или `α`; результат не обязан ухудшиться по ошибке классификации. |

**Числовые ориентиры для независимой проверки реализации**, полученные непосредственным вычислением формул при `numpy==2.3.5` и `α=1`. Это **контрольные значения спецификации**, а не отчёт о выполнении G1 веткой 04:

| Запись | `S_ref`, m/s² | `S_obs`, m/s² | `E_event`, m/s² | `ŷ_ref → ŷ_obs` | `e_ref → e_obs` |
|---|---:|---:|---:|---|---|
| `rest` | 0.030236726394 | 0.039481271255 | 0.105545200200 | `0 → 0` | `0 → 0` |
| `walk` | 0.404957682970 | 0.385989699825 | 0.741924644698 | `1 → 1` | `0 → 0` |

Допуск сверки этих округлённых значений — `1e−9`. Результат **специально не обязан** менять метку: эффект отчётливо виден в `E_event` и `ΔS`, даже когда классификатор остаётся верным.
