# G1 — протокол фактического запуска ветки 04

**Контракт:** `contract/G1_SPEC.md`, v1.0 от 2026-11-01. **Область:** исключительно G1. **Статус:** реализация выполнена и локально проверена; **G1 пока не принят** и переход к G2 не разрешён. Архив необходимо передать ветке 05 для внешнего read-only аудита, затем ветке 00 для решения.

## Окружение и команды

Фактическое окружение запуска: **Python 3.13.5**, **NumPy 2.3.5**, **Matplotlib 3.10.8**, **pytest 9.0.2** (Linux). В Git-репозитории проект при выполнении не находился: `git_commit_sha = null` в metadata. Использованы только локальные вычисления и синтетические данные.

Из корня проекта были **реально выполнены** команды:

```bash
python run_g1.py
python run_g1.py --alpha 0 --output-dir results/controls/alpha_0
python run_g1.py --alpha 0.5 --output-dir results/controls/alpha_0_5
python -m pytest -v
python reports/independent_check.py
```

## Числа из сохранённых CSV/NPZ

Формат: `S_ref`, `S_obs`, `ΔS`, `E_event`, m/s², с округлением **только для этой таблицы**; фактическая точность полей CSV выше.

| alpha | record | S_ref | S_obs | ΔS | E_event | Z ones | pred ref→obs | error ref→obs |
|---:|---|---:|---:|---:|---:|---:|---|---|
| 0 | rest | 0.030236726394446 | 0.030236726394446 | 0 | 0 | 0 | 0→0 | 0→0 |
| 0 | walk | 0.404957682969991 | 0.404957682969991 | 0 | 0 | 0 | 1→1 | 0→0 |
| 0.5 | rest | 0.030236726394446 | 0.032191241210656 | +0.001954514816210 | 0.052772600100002 | 60 | 0→0 | 0→0 |
| 0.5 | walk | 0.404957682969991 | 0.380106844039529 | −0.024850838930463 | 0.370962322348871 | 60 | 1→1 | 0→0 |
| 1 | rest | 0.030236726394446 | 0.039481271254547 | +0.009244544860101 | 0.105545200200003 | 60 | 0→0 | 0→0 |
| 1 | walk | 0.404957682969991 | 0.385989699824672 | −0.018967983145319 | 0.741924644697741 | 60 | 1→1 | 0→0 |

Для `alpha=1`, максимальное абсолютное отличие сохранённого результата от округлённых контрольных чисел §5: `rest ≤ 4.54e−13`, `walk ≤ 3.28e−13` (допуск `1e−9`), **PASS**. Проверено точное равенство массивов для повторных запусков при одинаковом окружении, фиксированность 200 отсчётов, маски и границ, сохранение исходного массива.

При `alpha=0.5` значения `E_event` ровно вдвое меньше значений при `alpha=1` с ошибкой меньше `1e−12`, **PASS**. При `alpha=0` данные точно совпадают с исходными, маска нулевая, `ΔS=E_event=0`, **PASS**.

Заметьте: `S_obs(walk,alpha=0.5) < S_obs(walk,alpha=1)`, что иллюстрирует оговорку §4 о **необязательной монотонности RMS**. Классификатор в этом примере не ошибается ни до, ни после порчи, что **не** является доказательством надёжности.

## Технические оговорки и границы

1. Сборка не зависит от внешнего датасета и не меняет параметры утверждённой спецификации. Единственный разрешённый параметр командной строки — `alpha∈[0,1]`; seed, порог, частота и формулы неизменяемы.
2. Числовые ориентиры спецификации воспроизводятся для **NumPy 2.3.5**, который явно закреплён; при иной версии программа завершает выполнение с сообщением об ошибке. Иная платформа/версии зависимостей не были здесь проверены.
3. Валидация научного качества, реальные датчики, детекция повреждений, восстановление, WISDM, split и G2/G3 отсутствуют намеренно.
4. Ни одна оценка качества реального классификатора, надёжности, научной новизны или воспроизводимости между разными окружениями не заявляется.
