# G1 — Лаборатория надёжности временных рядов (синтетическая демонстрация)

**Статус:** контракт `contract/G1_SPEC.md` v1.0 принят координатором 00 **для реализации**. Данный репозиторий — результат ветки 04, **не** решение о завершении G1. Переход к G2 не разрешён без независимого аудита 05 и решения 00.

Это учебная модель двух трёхосных 10-секундных записей условного динамического ускорения (гравитация удалена): `rest` и `walk`. Здесь **нет реальных показаний смартфона**, обученного классификатора, детектора дефектов, восстановления или научной проверки качества. Никакие значения не были подобраны по результатам.

## Требования и запуск

Python **3.11+** (реально проверено на Python 3.13.5); точные зависимости в `requirements.txt`: **NumPy 2.3.5, Matplotlib 3.10.8, pytest 9.0.2**. Для первого запуска установить пакеты из обычного Python-окружения. Дальнейший запуск **не требует сети, внешних данных или платных сервисов**.

Из **корня распакованного проекта**:

```bash
python -m pip install -r requirements.txt
python run_g1.py
```

**Единая команда самого G1:** `python run_g1.py`. Она генерирует все обязательные файлы в `results/`, по умолчанию `alpha=1.0`. Никаких внешних входных данных нет. Можно вместо установки requirements использовать `pip install -e '.[test]'` и запуск `g1-demo`.

Проверка трёх закреплённых режимов (выводы не перезаписывают основной):

```bash
python run_g1.py --alpha 0   --output-dir results/controls/alpha_0
python run_g1.py --alpha 0.5 --output-dir results/controls/alpha_0_5
python run_g1.py --alpha 1   --output-dir results
python -m pytest -v
```

Для Windows PowerShell команды те же, если `python` указывает на нужное окружение. При использовании venv активируйте его перед установкой пакетов. Если NumPy не версии 2.3.5, G1 завершится с понятной ошибкой, а не выдаст несверенные контрольные числа. `--config configs/g1.json` позволяет явно указать входную конфигурацию, но **все** поля, кроме `corruption.alpha`, сверяются с закреплённым контрактом. Любая другая попытка изменить параметры приводит к ошибке.

## Что именно происходит

1. Один генератор `Generator(PCG64(20261101))` выполняет **один** `standard_normal((2,3,200), dtype=float64)`. Из него создаются записи в порядке `rest`, `walk` (20 Гц, 200 отсчётов, время 0–9.95 с). `rest` — шум σ=0.03; `walk` — синусоидальные колебания с частотой 2 Гц, амплитудами `(0.8,0.5,0.3)`, фазами `(0,π/3,π/2)` плюс тот же вид шума.
2. На каждой записи ось **x** на полуинтервале индексов `[60,120)` (время `[3,6)` с) заменяется на `(1−α)·X_ref[x,i]+α·X_ref[x,59]`. Точка `59` — последняя **до** события; `120` не затрагивается. Оси y,z остаются без изменений.
3. Истинная маска `Z` отмечает **назначенные оператором точки инъекции**, а не обнаруженные изменения: 60 единиц **на запись** при α>0 и только нули при α=0. Даже совпавшие случайно числа внутри интервала отмечаются единицей.
4. Для каждой записи **отдельно** исходный и повреждённый сигнал подаются в один и тот же `RMS`-baseline с неизменным порогом **0.20 m/s²**. Среднее вычитается **отдельно по каждой оси**, а квадраты усредняются **по всем 3×200 элементам**.
5. Ошибка наблюдения `E_event` — RMSE **только по 60 заранее заданным отсчётам оси x**, независимо от суммы маски (поэтому существует и равна нулю при α=0). Это **не ошибка восстановления**.

## Выходные файлы

Каждый запуск создаёт в указанной директории:

| Файл | Содержание |
|---|---|
| `g1_arrays.npz` | `x_ref`, `x_obs`: `(2,3,200)`, `float64`; `mask`: `(2,3,200)`, `uint8`; `labels=[0,1]`; `time_s`: 200 временных точек. Без pickle. |
| `results.csv` | **2 строки**, по одной на запись, со всеми полями §6 спецификации; floats записываются с точностью repr(float), достаточной для восстановления float64. |
| `signal_comparison.png` | Шесть графиков: исходная и повреждённая ось x,y,z для каждой записи. Участок `[3,6)` помечен **только на графиках x**. |
| `mask.png` | Бинарная карта настоящих мест инъекции по осям и времени для **обеих** записей. Это не выход алгоритма обнаружения. |
| `config.json` | Все параметры утверждённого контракта, включая реальное `alpha`. |
| `metadata.json` | Версии Python/NumPy/Matplotlib, Git SHA (либо `null` без Git), SHA256 спецификации/выходов, ограничения эксперимента. |

Папка `results/controls/` содержит **реальные сохранённые выходы** α=0 и α=0.5, а корень `results/` — α=1. При повторном запуске данные детерминированно заменяются, но без создания дополнительных записей, без переобучения.

### Как читать каждый столбец CSV

| Столбец | Смысл |
|---|---|
| `record_id` | `rest` или `walk` — идентификатор одной искусственной записи. |
| `y` | Заранее присвоенный класс: 0 покой, 1 ходьба. |
| `seed` | Единственный seed генератора шума: 20261101. |
| `fs_hz` | Частота отсчётов: 20 Гц. |
| `alpha` | Сила вмешательства 0..1. При α=0 вмешательство тождественно. |
| `axis` | Повреждаемая ось (0=x). |
| `start_idx`, `end_idx` | Полуинтервал `[60,120)` отсчётов, не включая 120. |
| `S_ref_m_s2` | RMS исходной записи после вычитания среднего каждой оси, в m/s². |
| `S_obs_m_s2` | Тот же RMS повреждённой записи, в m/s². |
| `delta_S_m_s2` | `S_obs − S_ref`. Может быть положительным/отрицательным и не обязан монотонно зависеть от α. |
| `pred_ref`, `pred_obs` | Классы эвристики `int(S >= 0.20)` до/после, каждый 0 или 1. |
| `error_ref`, `error_obs` | `int(pred != y)` до/после: 0 — правильное решение, 1 — ошибка. |
| `rmse_event_m_s2` | `sqrt(mean((X_obs[x,60:120]−X_ref[x,60:120])²))`; сравнение с известным синтетическим эталоном, m/s². |

**Не вычисляем:** accuracy, balanced accuracy, статистическую неопределённость, эффективность детектора, качество восстановления или качество на людях. Изменение метки не обязано происходить. Два искусственных ряда — не независимая тестовая выборка для научных выводов.

## Проверяемость / аудит

Тесты проверяют seed, форму, метки, формулу генератора, строгое замирание и неизменность остальных отсчётов, назначенную маску (включая `α=0` и случай точного совпадения), ручные RMS и RMSE, фиксированность порога, повторные запуски, структуру и соответствие CSV/NPZ, контрольные числа §5.

Ожидаемые ориентиры **только для α=1** (допуск 1e−9):

| Запись | S_ref | S_obs | E_event | pred ref→obs | error ref→obs |
|---|---:|---:|---:|---|---|
| rest | 0.030236726394 | 0.039481271255 | 0.105545200200 | 0→0 | 0→0 |
| walk | 0.404957682970 | 0.385989699825 | 0.741924644698 | 1→1 | 0→0 |

Ориентиры — **данные утверждённой спецификации**. Фактические значения и результаты тестирования данного архива зафиксированы **отдельно** в `reports/EXECUTION_REPORT.md` и `reports/pytest_output.txt`. Для аудита **05** необходимо самостоятельно запустить команды и пересчитать контрольные числа, не исправляя оригинальные файлы молча.

Исходная спецификация сохранена байт-в-байт в `contract/G1_SPEC.md` (её заголовок исторически сохраняет статус `PROPOSED`, поскольку решение о GO **на реализацию** пришло отдельным поручением координатора). Устав — `contract/RESEARCH_LAB_CHARTER_v1.md`.
