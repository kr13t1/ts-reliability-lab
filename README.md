## Три независимых целевых выхода

1. **Инженерная лаборатория / Хабр:** готовая воспроизводимая демонстрация и технический материал после G3 и проверки 05. Хабр — не научная публикация.
2. **Первая научная статья:** отдельно по прежним исследованиям A/B (MI EEG/HFD-classification или HFD–U1), после самостоятельной проверки ближайшей литературы и качества результатов. Исторические EEG-архивы **НЕ находятся здесь**.
3. **НИР / будущая ВКР:** новая лаборатория как экспериментальная основа; постановка главной научной задачи только после G4 и G5. НИР может быть промежуточным отчётом, но полноценная ВКР не обещана заранее.

## Данные и ограничения

- Источник: WISDM UCI 507 / DOI `10.24432/C5HK59`; A = Walking, E = Standing (стояние, а не идеальный покой).
- В `data/provenance/` лежат **отчёты**, а не raw-файлы. Полный локальный UCI ZIP **не был независимо побайтно аттестован по серверу**: зафиксировано совпадение только префикса повторной загрузки (151 511 010 байт по локальному отчёту).
- 05 независимо проверила хеши трёх переданных raw TXT и числа строк; таймстампы в наносекундах остаются гипотезой, физические границы сеансов неизвестны. См. аудит 05 и LAB-017.
- Не включать в GitHub большой `uci507.zip` и сырые `data_*.txt`; хранить локально и использовать зафиксированные хеши.

**Не смешивать** проект C с прошлыми работами EEG (A/B), не проводить разбиение перекрывающихся окон между train и test и не подбирать алгоритм по test.
