# G2.3 — контролируемая заморозка реальной записи

LAB-023 / Issue #12 активирует §7 принятого контракта только для этой педагогической демонстрации. Принятый `g2/readonly.py` используется без изменений. Полный G2 NOT GO, G3 закрыт; результат ещё требует независимого аудита 05.

Из корня репозитория (Python 3.12; на Windows `py -3.12` вместо `python`):

```sh
python -m pip install -r g23/requirements.txt
python -m unittest discover -s g23/tests -v
python -m g23.freeze --input data/raw/data_1600_accel_phone.txt --output-dir /tmp/g23-demo --source-commit COMMIT_SHA
```

Указать полный SHA проверяемого исходного commit вместо COMMIT_SHA. Это записываемый идентификатор, не автоматическая проверка GitHub. При обычном git checkout дополнительно записываются фактический git SHA и dirty flag; для API-снимка они честно null. Проверяющий обязан сопоставить `source_sha256` с указанным commit. Каталог вывода должен быть новым/пустым. В Windows заменить `/tmp/g23-demo` своим новым каталогом.

Вход — полный неизменённый TXT 1600 из уже доступного транспортного raw-пакета; SHA `40b7f60880b495ccb3c345b9ab11216dfa6bbb2bb887bcb45fb55020278fc22f`. Сырые данные в Git отсутствуют. Нет подмены, автоматической загрузки или выбора другой записи. Precheck также закреплён полным SHA. Исходный `reference.csv` должен совпасть с принятым G2.2 SHA `8bf61ee71f68e0648ead7bc8eb8b6c44414e28411bd6de65e5f9dadf9c28eb38`.

Оба режима вычисляются вместе без случайности: alpha=0 ничего не меняет; alpha=1 удерживает x на значении индекса 1190 для индексов [1191,2382). Другие оси и q неизменны. Z — назначенная область, а не маска найденных природных дефектов. Для постоянного участка n_changed может быть меньше n_assigned вплоть до нуля.

Выход: `reference.csv`, `selection.json`, `alpha_0/arrays.csv`, `alpha_1/arrays.csv` (reference, observed, Z, точный q), два `comparison.png`, `results.csv/json`, config, validation, provenance с хешами всех выходов кроме самого provenance. D_Z в CSV имеет буквальное `null`, в JSON — null при пустой маске. D_I/D_Z — RMSE изменения в м/с² по документации; L_out — максимум изменения вне Z. Identity baseline ничего не восстанавливает. Графики содержат все точки по индексу без сглаживания, секунд или предположения ns.

Отказ возвращает exit code 2 и validation/provenance без результатов или графиков. Непустой выход отклоняется без перезаписи. PASS_DEMO — техническое исполнение, не независимый аудит и не научная эффективность. Тесты unittest работают без pytest; старые тесты G2.2 отдельно требуют g2/requirements.txt.
