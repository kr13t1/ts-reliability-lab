# Единственная следующая проверка — G2.1b / LAB-018

**Ответственная ветка: 02 — Данные.**

**Задача:** read-only найти именно первичный исходный код приложения-сборщика WISDM Smartphone and Smartwatch Activity and Biometrics Dataset (2019, UCI 507) **или его техническую спецификацию** и установить, каким вызовом/преобразованием формируется поле `timestamp` для `raw/phone/accel`.

**Проверяемая гипотеза:** timestamp записывается непосредственно из Android `SensorEvent.timestamp` (наносекунды, монотонная база). Не смешивать этот датасет с WISDM v1.1/Actitracker; не считать саму Android-документацию доказательством использования этого API приложением WISDM.

**Один артефакт:** `docs/g2/G2_TIMESTAMP_COLLECTOR_SOURCE_02.md` с исходными URL, идентификацией версии приложения/репозитория, точным кодом или номером строки и статусами CONFIRMED / ASSUMED / UNKNOWN. Если исходный код недоступен, записать, где искали, и отметить NOT FOUND / UNKNOWN — не заменять свидетельства догадкой.

**Входные материалы:** `docs/g2/G2_TIMESTAMP_SEMANTICS_02.md`, `data/provenance/G2_MULTI_SUBJECT_PRECHECK.json`, `docs/PROJECT_STATE.md`, `docs/DECISIONS.md`, отчёт независимого аудита 05 в общей библиотеке.

**Транспорт:** отдельная Git-ветка и Pull Request с одним MD-файлом; указать commit SHA; не сливать самостоятельно.

**Запреты:** не скачивать повторно большой UCI ZIP только ради этого, не менять raw/G1, не делать resampling, окна, split, обучение, классификацию, инъекции и новый метод. **Полный G2 не принят; G3 не открыт.**
