# Следующая единственная работа — математический контракт G2.2 (LAB-019)

**Ответственная роль: 03 — математический протокол.** Статус G1 — GO. G2.1 и G2.1b — GO только для ограниченных документальных проверок. Полный G2 НЕ GO, G3 закрыт.

**Задача:** предложить формальную, проверяемую спецификацию **первой иллюстрации реального WISDM-сигнала**, до создания окон и обучения. Достаточно одного фиксированного activity-run A или E у одного из заранее указанных subjects 1600/1601/1602. Предпочтительный выход после будущей реализации — исходная трёхосная траектория по индексам, явно сохранённые исходные целые timestamp, границы run, известная последующая маска контролируемого вмешательства (если и только если будет отдельно утверждена), единичный baseline и честное сравнение без утверждений о physical fault.

**Формализовать:** объект X_ref (это наблюдаемая запись, не идеально чистая истина), индексную шкалу и q_i в единицах файла, метод детерминированного выбора run по заранее зафиксированному правилу, границы и запреты склейки, отдельные условия фальсификации и отбраковки, маску Z и метрики лишь как предлагаемую будущую схему, происхождение raw, критерии независимого воспроизведения. Предположение `q-unit=ns` НЕ считать доказанным; запрещено искусственно унифицировать 20/25 Гц.

**Ограничения:** ни split/train/test, ни окон, ни ресемплинга, ни классификации и оценки ML. Не выдавать 3 subjects за научную репрезентативность. Не изменять G1 и raw. Отдельно пометить MAJOR-01 (внешний SHA полного UCI ZIP) как незакрытое условие для полного G2.

**Выход:** один проект `docs/g2/G2_REAL_SIGNAL_SPEC.md` со статусом PROPOSED в отдельном PR и точным commit SHA. До GO координатора 00 ветке 04 не писать код; 05 проверить контракт независимо после решения 00 о необходимости аудита. Не сливать без 00.

**Источники:** `docs/g2/G2_TIMESTAMP_SEMANTICS_02.md`, `docs/g2/G2_TIMESTAMP_COLLECTOR_SOURCE_02.md`, `data/DATASET_CARD_G2_DRAFT.md`, `data/provenance/G2_MULTI_SUBJECT_PRECHECK.json`, `docs/PROJECT_STATE.md`, `docs/DECISIONS.md` и Charter.
