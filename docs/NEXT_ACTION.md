# Единственное следующее исследовательское действие (по LAB-017)

**Ветка 02:** подготовить read-only `G2_TIMESTAMP_SEMANTICS_02.md` на основании авторской документации WISDM и уже проверенных raw-отчётов. Для каждого утверждения дать `CONFIRMED / ASSUMED / UNKNOWN`: физическая единица timestamp; объяснимость различия интервалов 1601 против 1600/1602; границы серий и отсутствие подтверждённых session ID. Выход — ссылки на первоисточники, численные проверки и ограничения.

**Запрет:** не ресемплировать сигналы, не формировать окна, не проводить train/val/test, ML, инъекции повреждений, не предлагать новый метод. Полный G2 не принят, G3 не открыт.

**Передать ветке 00:** один MD-файл (можно ссылкой на файл в GitHub после создания репозитория). 00 проверяет и принимает/отклоняет чекпоинт; после этого отдельное решение по G2.
