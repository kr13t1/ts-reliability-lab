## 3. Независимая математика и реальное выполнение

Заданный `a=1191`, `b=2382`, (I=[1191,2382)), (b-a=1191). Точное исходное удерживаемое значение `X_ref[0,1190]=0.43917847`. В режиме `alpha=1` `X_obs[0,1191:2382]=X_ref[0,1190]`, и только эти 1191 элементов оси X получают `Z=1`. Все остальные значения X, все Y/Z и все временные метки остались неизменными. **Маска формируется по назначенной области вмешательства**, а не по разности `X_obs-X_ref`.

Ни одна функция `g23.freeze`/`g23.metrics` не использовалась в **отдельном независимом математическом пересчёте**: raw TXT непосредственно разбирался другим скриптом, обе наблюдаемые матрицы и маски строились заново, метрики вычислялись по §7 с знаменателем **1191**, а не 3N.

| Утверждение / метрика | `alpha=0` | `alpha=1` |
|---|---:|---:|
| `n_assigned` | 0 | 1191 |
| `n_changed` | 0 | 1191 |
| `D_I` | 0.0 | 3.0753845270371265 |
| `D_Z` | **null** | 3.0753845270371265 |
| `D_Z_status` | NOT_APPLICABLE | DEFINED |
| `L_out` | 0.0 | 0.0 |
| `outside_identical` | true | true |

Разделение `n_assigned` и `n_changed` корректно в коде; **отдельный тест нулевого эффекта** на константном искусственном ряде показал `n_assigned=2, n_changed=0, D_Z=0`, то есть mask ≠ индикатор отличия амплитуд. В реальном ряду все назначенные 1191 значений оказались изменены — это результат проверенного конкретного входа, а не математическая необходимость.
