## 3. Локальный запуск и артефакты

**Среда:** Linux, Python 3.13.5, NumPy 2.3.5, Matplotlib 3.10.8, pytest 9.0.2.


## 5. Замечания

**CRITICAL — 0.** Искажения raw/CSV/q, неправильного адресного выбора, фальсификации графика, запрещённых операций или научных заявлений не обнаружено.

**MAJOR-01 — неполнота обязательных provenance-полей (§5).** Выходной `config.json` содержит лишь текстовое имя контракта, **не содержит точного утверждённого SHA спецификации** (утверждённый head `ae612e338df6a25eb94281cc2b3969cd39824d44`; файл в frozen checkout имеет Git blob `fe966d72bd60be2a0abc21bdc158bd53d2f896b3`). В `provenance.json` отсутствуют **фактически выполненная команда/CLI-аргументы** и **атрибуция UCI 507 / DOI / лицензии**, явно требуемые §5. README содержит атрибуцию, а provenance хеши/версии сохранены, но контракт outputs выполнен не полностью. **Закрыть:** в отдельном исправляющем commit явным образом включить утверждённый SHA спецификации, команду/аргументы воспроизведения, UCI 507, DOI 10.24432/C5HK59, CC BY 4.0 и честное `UNVERIFIED` full source; добавить тест на обязательные поля JSON. Не задним числом подменять `git_sha=null`.

**MAJOR-02 — неконтролируемый отказ на структурно неправильном precheck (§§4–5).** При существующем `precheck.json` со структурой `{}` функция `select_from_precheck()` выбрасывает не перехватываемый `KeyError` без `validation.json` и статуса `REJECTED_INPUT`. CSV/PNG не генерируется, но требование записи отказа нарушено. **Закрыть:** проверить структуру/типы JSON до выбора, перехватывать ошибки структуры как `Refusal('REJECTED_INPUT', ...)`, писать `validation.json` при каждом штатном отказе, покрыть пустой/неполный/неверно типизированный precheck дополнительными тестами.

**MINOR-01 — полный precheck checksum не сравнивается с закреплённым.** В provenance сохраняется `precheck_sha256`, однако само содержание precheck до выполнения не сверяется с ожидаемым `f534d093b003327019dec214c1c332e95c1d413ad25efd7943df4082422e8a57`. Технически CSV выбранного run при этом остаётся корректным, но формулировка «закреплённый JSON» имеет более слабую реализацию. **Закрыть:** закрепить SHA precheck и требовать его совпадения либо документированно согласовать с 00 pin только инвариантов выбора; добавить тест.

**Унаследованные ограничения полного G2:** нет внешней полной аттестации официального UCI ZIP, нет доказанной единицы времени q и независимых session IDs. Не подменять факты гипотезой о наносекундах или реальных неисправностях.
