# Три выхода проекта

| Ветка | Практический результат | Критерий готовности | Зависимость |
|---|---|---|---|
| 1. Инженерный / Хабр | Воспроизводимый GitHub-стенд, демонстрация трех типов сбоев, простые baseline, графики, объяснение и ограничения, техническая статья | Готовая Lab v1, тесты и аудит; Хабр отдельно не является рецензируемой научной статьёй | G2 → G3 → аудит → публикация |
| 2. Научная статья A/B | Отдельная научная статья по прежним EEG/HFD результатам, без имитации новизны | Выбор между A и B по проверенным результатам, обзору аналогов и требованиям издания; отдельный GO 00 | Старые архивы A/B и отдельный независимый обзор; НЕ из WISDM |
| 3. НИР / ВКР C | НИР на основе реальной лаборатории; потенциальная бакалаврская ВКР с одной формальной исследовательской проблемой | НИР по требованиям; для ВКР G4/G5, гипотезы, протокол, воспроизводимость и аудит G6 | G2 → G3 → G4/G5 → G6 |

Вклад, качество и положительные результаты заранее не гарантируются.
