# Три действующие цели проекта C — решение LAB-033 / 2026-11-04

**Единая исследовательская область:** надёжность алгоритмов при контролируемых повреждениях многоканальных измерительных временных рядов. **Решение пользователя:** действующая научная статья будет **новой, именно по этому направлению**; прежние статьи/архивы не входят в активный план и не смешиваются с C.

| Продукт | Предмет | Что нужно для действительной готовности |
|---|---|---|
| **1. Инженерная лаборатория и Хабр** | На реальном WISDM показать `X_ref → X_obs`, проектную маску `Z`, предсказанную `Zhat`, последствия для алгоритмов, интерактивный выбор сценария | Переносимая работающая CLI/UI, ясный контрольный пример, показ отрицательных случаев, точные команды, неизменные воспроизводимые результаты и аудит. Хабр **не** научное доказательство/автоматически зачётная публикация |
| **2. Новая научная статья по проекту C** | Строгая проверка конкретной проблемы надёжности: существующие baseline, их уязвимость, **кандидат собственного метода** и обоснованное сравнение | После G4 prior art, G5 математический контракт, честные independent-group splits, фиксированный протокол, статистический анализ и 05 аудит результатов; подтверждённое улучшение **не гарантировано**, пока нет научного вклада и темы статьи |
| **3. НИР-7 и будущая ВКР по C** | Теория ошибок измерения, математическая постановка, воспроизводимая лаборатория, собственный метод при обоснованной научной нише | Проверить актуальные учебные требования, подготовить обзор/формулы/эксперименты/отчёт и защиту. **Тема ВКР не утверждена до G4/G5** |

**Общая экспериментальная база**, но независимые критерии публикации/защиты. Будущий блок **Research & Invention** обязателен по намерению пользователя: выбрать *одно* существенное слабое место baseline и попытаться опровергнуть улучшение нового метода; никаких claims о новизне до первоисточников и аудита.

**Текущая проверенная база:** G1/G2.2/G2.3/G2.4 — ограниченные технические GO, viewer — presentation-only GO в аудированной Linux-среде (LAB-032). **Full G2 NOT GO, G3 CLOSED**. Пользователь получил `g24.demo PASS_DEMO` на Windows, но локально viewer дал `REJECTED_INPUT` из-за Windows path separators в provenance и отличающихся PNG fingerprints при совпавших четырёх CSV SHA. Статический предпросмотр **не является интерактивной лабораторией**.

**Ровно одна следующая техническая проверка:** формально воспроизвести этот Windows cross-platform failure с исходными неизменными outputs и зафиксировать ожидаемую корректную реакцию перед отдельным минимальным исправлением и аудитом. Новые алгоритмы и исследовательские этапы не открываются.
