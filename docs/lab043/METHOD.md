# Что измерялось

**Вход.** В записи телефонного акселерометра WISDM 1601 непрерывная последовательность Walking (код A) занимает строки 1–4512. Пусть $x_i$ — наблюдаемое ускорение X по исходному индексу, принятому за эталон для искусственной замены. Нумерация индексов с нуля. Метки времени сохранены как исходные целые числа. Длины и разности заданы по индексам.

**Вмешательство.** Для интервала $I=[s,s+L)$ назначить маску на оси X и заменить каждое значение внутри на $x_{s-1}$. Остальные оси и значения вне маски сохраняются. Границы назначенной замены известны методу заранее (oracle mask). Числа назначенных и фактически изменённых значений приведены в [таблице сценариев](evidence/scenarios.csv). Старты 400, 800, 1200, 1600, 2000, 2400, 2800, 3200 пересекаются с четырьмя длинами 5, 20, 80, 200 в фиксированной сетке из 32 сценариев.

| Заполнение | Доступная информация и правило |
|---|---|
| Hold | Повторяет последнее наблюдение слева $a=x_{s-1}$. Совпадает с искусственным замиранием. |
| Linear | Для $j=0,\dots,L-1$ возвращает $a+(j+1)(x_{s+L}-a)/(L+1)$. Правая граница доступна после окончания интервала. |
| AR(10) | На 256 предшествующих значениях X методом наименьших квадратов оцениваются свободный член и 10 коэффициентов лагов (246 обучающих строк). Следующий шаг вычисляется по последним десяти значениям, уже сделанные прогнозы поступают на вход следующих шагов. |

Для всех 96 сочетаний метода и окна сначала зафиксированы прогнозы, затем открыт эталон для оценивания. Linear получает дополнительное будущее наблюдение. Детекция границ и настройка по целевой записи в задачу не входят. ## Два вопроса к одному восстановлению

Обозначим восстановленное значение через $y_i$, а приращение между соседними индексами через $\delta x_i=x_{i+1}-x_i$. Аналогично определим $\delta y_i$.

**Насколько близки сами значения?** Среднеквадратичная ошибка внутри маски имеет размерность ускорения.

$$
E=\sqrt{\frac{1}{L}\sum_{i=s}^{s+L-1}(y_i-x_i)^2}.
$$

**Насколько точно переданы изменения от отсчёта к отсчёту?** Пусть $A$ — RMS ошибки внутренних приращений, $B$ — RMS приращений эталона. Оба вычисляются на одних и тех же $L-1$ парах. Переходы через края исключены.

$$
D=\frac{A}{B}=\sqrt{\frac{\sum_{i=s}^{s+L-2}(\delta y_i-\delta x_i)^2}{\sum_{i=s}^{s+L-2}(\delta x_i)^2}}.
$$

При точном совпадении приращений D=0. У Hold все приращения нулевые, поэтому при B>0 получается D=1. D может превышать 1. Деления на время здесь нет. При нулевом знаменателе D неопределена. Отдельное описательное отношение $V=\mathrm{Var}_I(y)/\mathrm{Var}_I(x)$ характеризует разброс значений в окне при ненулевой дисперсии эталона.

Для обоих показателей ошибки меньшее значение лучше. Основная пара заранее задана при L=200. Знаки разностей AR минус Linear учитывают допуск $10^{-10}$. Совместное расхождение означает, что в одном окне ΔE отрицательна и ΔD положительна. Порог знака служит численной устойчивости.
