Из каталога этого комплекта в Linux проверить контрольные суммы. Для прямой сверки с CI нужен доступ к приватному артефакту. Сохранить скачанный ZIP как evidence.zip вне репозитория и указать его путь. Команды только читают готовые результаты.

```sh
sha256sum -c SHA256SUMS
archive=/path/to/evidence.zip
echo "d1a3ac7b2586c781b225e46fce92e74ecd55d433a1aff650b1816f757394e16b  $archive" | sha256sum -c -
python - "$archive" <<'PY'
import sys
from pathlib import Path
from zipfile import ZipFile
with ZipFile(sys.argv[1]) as z:
    for path in sorted(Path("evidence").iterdir()):
        for mode in ("normal", "optimized"):
            if path.read_bytes() != z.read(f"{mode}/{path.name}"):
                raise SystemExit(f"Расхождение: {mode}/{path.name}")
print("Все копии совпадают побайтно")
PY
```

Для проверки основного вывода открыть summary_paired.csv, выбрать L=200 и пару AR(10) - Linear. Проверить paired_E_mean, paired_D_mean, D_+, D_-, joint_count и n_valid. В paired.csv тот же фильтр оставляет восемь стартов. Для иллюстрации выбрать в results.csv s=1200, L=200 и прочитать E, D, V по методу. В комплекте 32 строки сценариев, 96 строк методов, 96 пар и по 12 строк двух сводок, без заголовков.

## Что выдерживает проверку

- Единственная условно допущенная запись, зависимые сценарии и общие участки контекста. История частного доступа к данным неизвестна. Обобщение на людей или сеансы, статус нетронутого теста и практическая значимость открыты.
- Исходные значения реально измерены. Искусственное замирание с известной маской позволяет сравнить заполнения. Надёжность обнаружения аппаратного отказа и влияние на распознавание активности здесь не оценивались. Выводов о новизне метода нет.
- D описывает индексные приращения. Данных для вывода о восстановлении физической производной, спектра или биомеханики шага это сравнение не даёт.
- CI выполнил 35/35 тестов в каждом режиме. Режимы обычного Python и Python -O подтверждены командами и логами CI. В provenance реального запуска нет отдельного поля optimize. Два старых CSV пилота оказались изменены во временной рабочей копии по неизвестной причине. Все 18 проверенных путей к исполняемым файлам и документам, задающим протокол и допуск, совпали с закреплённой версией.
- Аудитор независимо воспроизвёл арифметику из ранее доступных исходных данных и проверил результаты в обоих режимах. Полную CLI-процедуру с официальным скачиванием аудитор локально не повторял. Полный G2 — NOT GO, G3 — CLOSED.
- Исходные записи, reference.csv и массивы отсчётов остаются за пределами комплекта. Для редакционной проверки достаточно четырёх PNG, пяти CSV и атрибуции. Публичное размещение материалов рассматривается отдельно.
